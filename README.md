# GPS sky trails

A timelapse simulation of GPS satellite trails across the sky, as seen looking straight up (360-degree fisheye view) from Nettleton Hill, West Yorkshire.

Simplified circular-orbit model: 24 satellites across 6 orbital planes at 55 degree inclination, ~12-hour period. Each colour is one orbital plane. This is an illustrative model, not real ephemeris data.

## Running locally

Just open `index.html` in a browser — no build step or dependencies.

## Deploying with GitHub Pages

1. Push this repo to GitHub.
2. In the repo, go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Save. GitHub will publish the site at `https://<your-username>.github.io/<repo-name>/`.
